## 서버 요구사항

```
메모리    1GB 이상 권장 (컨테이너 실측 275MB, 빌드 시 더 필요)
vCPU     많을수록 좋다. OCR 이 CPU 바운드다
         0.5 vCPU 에서 사진 1장 44초. 1 vCPU 이상을 권한다
디스크    5GB (이미지 1.4GB + 여유)
```

## 빌드를 어디서 할 것인가

**이미지가 1.4GB 고 빌드에 메모리를 많이 쓴다.** 1GB 짜리 VPS 에서
`docker build` 를 돌리면 OOM 으로 죽을 수 있다. 두 길이 있다.

### A. 로컬에서 빌드하고 레지스트리로 보낸다 (권장)

```bash
# 로컬 (메모리 넉넉한 곳)
docker build -t medcheck .
docker tag medcheck <계정>/medcheck:latest
docker push <계정>/medcheck:latest

# 서버
docker pull <계정>/medcheck:latest
docker run -d --name medcheck --restart always -p 80:7860 <계정>/medcheck:latest
```

Docker Hub 무료 계정이면 공개 저장소를 쓸 수 있다.
**이미지에 개인정보가 없다.** 코드, 모델, 식약처 공개 데이터뿐이다.

### B. 서버에서 직접 빌드한다

메모리가 2GB 이상일 때만.

```bash
git clone https://github.com/RL9-csv/medcheck.git
cd medcheck
docker build -t medcheck .
docker run -d --name medcheck --restart always -p 80:7860 medcheck
```

## 환경 변수

Dockerfile 에 기본값이 박혀 있다. 서버 사양에 맞춰 덮어쓴다.

```bash
docker run -d --name medcheck --restart always -p 80:7860 \
  -e OCR_THREADS=2 \
  -e OMP_NUM_THREADS=2 \
  medcheck
```

**`OCR_THREADS` 를 vCPU 수에 맞춘다.** 많이 준다고 빨라지지 않는다.
실측에서 4스레드 12.8초, 24스레드 25.8초, 1스레드 29.8초였다.
**vCPU 수와 같게 두고 시작한 뒤 실측으로 조정한다.**

`ANTHROPIC_API_KEY` 는 넣지 않는다. 없으면 문장 다듬기 단계를 건너뛰고
템플릿 문장이 그대로 나간다. 키를 넣으면 약 이름이 토큰으로 가려진
문장이 외부로 나간다.

## 확인

```bash
curl http://<서버>/health          # {"ok": true}
curl http://<서버>/ready           # 모델 로드 완료 여부
```

**기동에 10~15초 걸린다.** 카탈로그 적재, OCR 모델 로드, 샘플 봉투
미리 읽기를 그때 한다. `/ready` 가 참이 될 때까지 기다린다.

기동 로그에 이런 줄이 나와야 정상이다.

```
{"event": "startup", "stages_ms": {"catalog_preload": ..., "ocr_warmup": ...,
 "sample_preload": ...}, "ocr": "rapid", "catalog_items": 19441}
```

`sample_preload` 가 없으면 첫 방문자가 13초를 기다린다.

## HTTPS

**도메인 없이 HTTPS 를 받는 건 위험하다.** `sslip.io` 같은 와일드카드
DNS 는 Let's Encrypt 주간 발급 쿼터가 소진돼 막힌 사례가 있다.

### 도메인이 있으면 — Caddy 가 제일 간단하다

```bash
# /etc/caddy/Caddyfile
your-domain.com {
    reverse_proxy localhost:7860
}
```

Caddy 가 인증서를 자동으로 받고 갱신한다.

### 도메인이 없으면

관리형 플랫폼(HTTPS URL 기본 제공)을 쓰는 편이 낫다. VPS 를 쓰면서
도메인이 없으면 DuckDNS 같은 무료 서브도메인 + DNS-01 인증을 써야
하는데, 이건 미리 테스트하지 않으면 배포일에 막힌다.
